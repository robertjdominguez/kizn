kizn

A desktop app for learning something properly. A model you choose writes practice ahead of time; code grades it, schedules it, and tells you plainly what's left before you're ready.

macOS and Linux
curl -fsSL https://kizn.app/install.sh | sh
Windows (PowerShell)
irm https://kizn.app/install.ps1 | iex

Installs for your user only, after checking the download's SHA-256. Remove it with --uninstall (-Uninstall on Windows); your data stays unless you add --purge. You'll need a model to learn with: a local one or a key for a provider.

The first release (v0.1.0) isn't out yet, so these lines won't work until it is.
